Домашнее задание: работа с файлами (os, bufio, defer, encoding/csv)

Чтение и запись

1. Сохрани список из 5 задач (строки) в файл tasks.txt через os.WriteFile, затем прочитай файл и выведи задачи в консоль пронумерованными, начиная с 1.

2. Напиши функцию countLines(filename string) (int, error), которая читает файл построчно через bufio.Scanner и возвращает количество строк. Проверь на файле из задания 1.

3. Напиши функцию copyFile(src, dst string) error. Открой исходный файл на чтение, целевой - на запись (os.Create), скопируй содержимое (можно через os.ReadFile + os.WriteFile или через io.Copy). Не забудь defer Close() для обоих файлов.

4. Напиши функцию grep(filename, word string) ([]string, error), которая построчно читает файл через bufio.Scanner и возвращает срез строк, содержащих заданное слово (без учёта регистра).

Работа с CSV

5. Заведи структуру Product (Name string, Price float64, Quantity int). Напиши функцию writeProductsCSV(filename string, products []Product) error по образцу writeCSV из примера 08-csv, затем прочитай файл обратно через encoding/csv и выведи таблицу в консоль.

Построчная обработка

6. Напиши функцию addLineNumbers(src, dst string) error: читает src построчно через bufio.Scanner, к каждой строке спереди добавляет номер вида "1: ", и построчно пишет результат в dst через bufio.Writer (не забудь Flush).

7. Напиши функцию mergeFiles(file1, file2, dst string) error, которая по очереди дописывает содержимое двух файлов в третий (сначала file1, потом file2).

Логирование

8. По образцу примера 09-logger напиши свой Logger с уровнями INFO/WARN/ERROR, но добавь метод, который одновременно пишет сообщение и в файл, и в консоль через fmt.Println.

Задачи со звёздочкой

9. Напиши функцию sortLines(src, dst string) error: читает файл построчно, собирает все строки в срез, сортирует его по алфавиту (sort.Strings), записывает результат в новый файл.

10. Напиши функцию tail(filename string, n int) ([]string, error), которая возвращает последние n строк файла. Подсказка: собери все строки в срез построчно, затем верни последние n элементов среза.

Итоговый проект: Персональный дневник

Программа с меню в консоли (постоянный цикл, ввод через bufio.Scanner из os.Stdin):
1. Добавить запись - сохраняет текст с текущей датой и временем в файл diary.txt (дозаписью, os.O_APPEND, а не перезаписью).
2. Показать все записи - построчно читает diary.txt и выводит их в консоль.
3. Найти по слову - выводит только те записи, которые содержат заданное пользователем слово, вместе с их датой.
4. Статистика - количество записей, общее число слов во всех записях, самая длинная запись, дата первой и последней записи.
5. Выход.

Что считается сделанным: в диктофоне-дневнике и в задачах 1-10 везде, где открывается файл, сразу после успешного открытия стоит defer f.Close(); все ошибки от файловых операций проверяются и выводятся с понятным текстом, а не игнорируются через _; там, где нужна дозапись (лог, дневник), используется os.OpenFile с os.O_APPEND, а не os.WriteFile/os.Create, которые стирают старое содержимое; там, где используется bufio.Writer, вызван Flush() (через defer или явно) перед закрытием файла.
