Домашнее задание №1

Тема:
Основы SQL CRUD и подключение Go к PostgreSQL.

Цель:
Научиться создавать таблицы, добавлять, получать, изменять и удалять данные с помощью SQL.
Познакомиться с подключением Go-приложения к PostgreSQL через database/sql.


============================================================
Задание 1. Создание таблицы
============================================================

В базе данных coursedb создайте таблицу books.


Таблица должна содержать следующие поля:

• id          — SERIAL PRIMARY KEY
• title       — TEXT NOT NULL
• author      — TEXT NOT NULL
• price       — INT NOT NULL
• pages       — INT NOT NULL
• created_at  — TIMESTAMP WITH TIME ZONE DEFAULT NOW()


============================================================
Задание 2. Добавление данных
============================================================

Добавьте в таблицу books минимум 15 книг.


Требования:

- все книги должны иметь разные названия;
- разные авторы;
- разные цены;
- разное количество страниц.


Добавление выполнить через INSERT.


============================================================
Задание 3. Получение всех данных
============================================================

Напишите SQL-запросы:

1. Вывести все книги.

2. Вывести только:
- название книги;
- автора.


3. Вывести:
- название;
- цену.


============================================================
Задание 4. Фильтрация данных WHERE
============================================================

Выполните запросы:

2. Найти книги стоимостью больше 100.


3. Найти книги стоимостью меньше 50.


4. Найти книги, количество страниц которых больше 500.


5. Найти книги с ценой от 100 до 200.


============================================================

2. Найти книги дешевле 100 или количеством страниц меньше 200.


3. Найти книги определённого автора и ценой больше 150.

AND
OR

3. Вывести книги по количеству страниц от большего к меньшему.


4. Вывести книги по названию в алфавитном порядке.


Использовать:

ORDER BY
ASC
DESC

============================================================
Задание 14. Подключение Go к PostgreSQL
============================================================

Создайте Go-программу.


Она должна:


- подключиться к PostgreSQL через database/sql;
- проверить подключение через Ping();
- вывести:


Подключение успешно установлено.


Использовать:

- github.com/lib/pq
- sql.Open()
- db.Ping()


============================================================
Задание 15. Подключение Go через пул соединений
============================================================

Создайте Go-программу.


Подключиться к PostgreSQL.


Настроить пул соединений:


- максимальное количество соединений;
- количество свободных соединений;
- время жизни соединения.


Использовать:


- SetMaxOpenConns()
- SetMaxIdleConns()
- SetConnMaxLifetime()


После подключения вывести информацию:


- количество открытых соединений;
- количество активных соединений;
- количество свободных соединений.

Создать небольшую программу на Go:

============================================================
Требования к выполнению
============================================================

1. Использовать PostgreSQL.

2. Использовать package database/sql.
(	_ "github.com/lib/pq" драйвер для работы с postgres)

3. Не использовать ORM.

4. Все SQL-запросы выполнять самостоятельно.

5. Использовать параметры запросов ($1, $2).

6. Обрабатывать ошибки.

7. При работе с Query() закрывать rows через defer rows.Close().

8. Код должен запускаться без ошибок.
