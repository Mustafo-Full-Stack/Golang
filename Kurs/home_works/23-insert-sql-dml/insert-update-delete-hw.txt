Тема:
INSERT, UPDATE, DELETE

===========================================
База данных
===========================================

Создайте таблицу books.

Структура таблицы:

id SERIAL PRIMARY KEY
title TEXT
author TEXT
price INT
pages INT
created_at TIMESTAMP DEFAULT NOW()

===========================================
Практика на Go
===========================================

Используя package database/sql:

1. Подключитесь к PostgreSQL.

2. Добавьте новую книгу через Exec().

3. Измените цену книги через Exec().

4. Удалите книгу по id через Exec().

5. Получите id новой книги
   через INSERT ... RETURNING id.

6. Выведите все книги в консоль.
