Домашнее задание: JSON

Сериализация (struct -> JSON)

1. Опиши структуру `Book` с полями `Title` (string), `Author` (string), `Year` (int) и `Price` (float64). Создай значение, преврати его в JSON с помощью `json.Marshal` и выведи результат на экран как строку. Не забудь обработать ошибку.

2. Опиши структуру `User` с полями `Name` (string), `Age` (int) и `Email` (string). Добавь к каждому полю тег так, чтобы в JSON ключи были в нижнем регистре: `name`, `age`, `email`. Создай значение, сериализуй и выведи JSON.

3. Опиши структуру `Product` с полями `ID` (int), `Name` (string), `Price` (float64) и `InStock` (bool). С помощью тегов задай ключи `id`, `name`, `price` и `in_stock`. Создай значение и выведи его в красивом виде через `json.MarshalIndent` (отступ — два пробела).

4. Опиши структуру `Student` с полями `Name` (string), `Grade` (int) и `Comment` (string). Для поля `Comment` добавь опцию `omitempty`. Создай двух студентов: одного с комментарием, другого без. Сериализуй обоих и сравни, чем отличается JSON.

5. Опиши структуру `Account` с полями `Login` (string), `Password` (string) и `Balance` (float64). Для поля `Password` поставь тег `json:"-"`, чтобы пароль не попадал в JSON. Создай значение, сериализуй и убедись, что пароля в выводе нет.

Десериализация (JSON -> struct)

6. Дана строка с JSON:
   {"title":"Go для начинающих","author":"Иван Петров","year":2023}
   Опиши подходящую структуру с тегами и преврати строку в структуру с помощью `json.Unmarshal`. Выведи каждое поле отдельной строкой.

7. Дана строка с JSON:
   {"name":"Алия","age":20,"city":"Душанбе"}
   Опиши структуру `Person`, у которой есть только поля `Name` и `Age` (поля `city` в структуре нет). Выполни `Unmarshal` и выведи результат. Что произошло с лишним ключом `city`? Напиши ответ комментарием в коде.

8. Дана строка с JSON:
   {"name":"Ноутбук","price":4500.5}
   Опиши структуру `Item` с полями `Name` (string), `Price` (float64) и `Count` (int) с тегами `name`, `price`, `count`. Выполни `Unmarshal` и выведи структуру. Какое значение получило поле `Count`, которого нет в JSON? Напиши ответ комментарием в коде.

Вложенные данные

9. Опиши структуру `Address` с полями `City` и `Street` (string) и структуру `Person` с полями `Name` (string), `Age` (int) и `Address` типа `Address`. Задай теги: `name`, `age`, `address`, `city`, `street`. Создай значение `Person`, сериализуй его через `MarshalIndent`, а затем полученный JSON преврати обратно в новую структуру через `Unmarshal` и выведи город.
