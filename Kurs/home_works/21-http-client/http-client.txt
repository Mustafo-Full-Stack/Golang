Домашнее задание: HTTP-клиент (net/http)

Публичные API для задач: https://jsonplaceholder.typicode.com и https://httpbin.org

1. Отправь GET-запрос на https://jsonplaceholder.typicode.com/posts/1. Выведи статус-код, значение заголовка ответа Content-Type и тело ответа как строку.

2. Отправь GET-запрос на https://jsonplaceholder.typicode.com/users/1 клиентом с таймаутом 5 секунд. Разбери ответ в структуру с полями id, name, email, phone и выведи имя, email и телефон.

3. Запроси по очереди https://jsonplaceholder.typicode.com/todos/5 и https://jsonplaceholder.typicode.com/todos/99999. Для каждого выведи статус-код. Если статус 200 — выведи title задачи, если 404 — выведи "Задача не найдена".

4. Запроси https://jsonplaceholder.typicode.com/todos клиентом с таймаутом 5 секунд. Выведи, сколько задач выполнено (completed: true), а сколько нет.

5. Запроси https://jsonplaceholder.typicode.com/posts клиентом с таймаутом 5 секунд. Выведи количество постов, а также title первого и последнего поста.

6. Получи посты пользователя с userId=3 (адрес https://jsonplaceholder.typicode.com/posts, userId передай как query-параметр). Выведи количество постов и title каждого.

7. Отправь GET-запрос на https://httpbin.org/headers, добавив в запрос заголовок X-Student со своим именем. Выведи тело ответа и убедись, что твой заголовок в нём есть.

8. Запроси https://httpbin.org/delay/2 клиентом с таймаутом 1 секунда — выведи полученную ошибку. Затем отправь тот же запрос клиентом с таймаутом 5 секунд — выведи статус-код.

9. Для кодов 200, 201, 404, 500, 503 запроси https://httpbin.org/status/<код> клиентом с таймаутом 5 секунд. Для каждого выведи "<код>: успех", "<код>: ошибка клиента" или "<код>: ошибка сервера".

10. Отправь POST-запрос на https://jsonplaceholder.typicode.com/posts клиентом с таймаутом 5 секунд. Тело — JSON с полями title, body и userId (равен 1). Выведи статус-код и id созданного поста из ответа.

11. Отправь DELETE-запрос на https://jsonplaceholder.typicode.com/posts/1 клиентом с таймаутом 5 секунд и выведи статус-код.

12. Запроси https://jsonplaceholder.typicode.com/users клиентом с таймаутом 5 секунд. Для каждого пользователя выведи name и название его компании (company.name).

Задачи среднего уровня

13. Напиши структуру APIClient с полем baseURL и http-клиентом с таймаутом 5 секунд, конструктор NewAPIClient(baseURL string) и два метода: GetUser(id int) и GetUserPosts(userID int). Если сервер вернул статус, отличный от 200, метод возвращает ошибку с этим статусом. В main создай клиент с baseURL https://jsonplaceholder.typicode.com, получи пользователя 1 и его посты, выведи имя и количество постов. Затем запроси пользователя 11 и выведи полученную ошибку.

14. Для поста с id 1 выведи отчёт: заголовок поста, имя автора (пост хранит только userId, имя нужно запросить отдельно), количество комментариев к посту и email каждого комментатора. Все запросы выполняются последовательно одним клиентом с таймаутом 5 секунд.

15. Запроси https://jsonplaceholder.typicode.com/todos. Для каждого userId по возрастанию выведи количество выполненных и невыполненных задач, а в конце выведи id пользователей, у которых выполнено больше половины задач.

16. Запроси пользователей с id от 1 до 10 (https://jsonplaceholder.typicode.com/users/<id>) одновременно через горутины и WaitGroup, каждая горутина кладёт результат в свою ячейку среза. Выведи имена по порядку id и общее время работы. Затем выполни те же 10 запросов последовательно и выведи время работы обоих вариантов рядом.

17. Напиши функцию getWithRetry(url string): она отправляет GET-запрос клиентом с таймаутом 3 секунды, делает максимум 3 попытки с паузой 1 секунда между ними. Повторяет попытку при ошибке запроса или статусе 5xx; при статусе 4xx и 2xx сразу завершается без повторов. В main вызови функцию для https://httpbin.org/status/200, https://httpbin.org/status/404 и https://httpbin.org/status/503 и для каждого выведи итоговый статус-код и количество сделанных попыток.
