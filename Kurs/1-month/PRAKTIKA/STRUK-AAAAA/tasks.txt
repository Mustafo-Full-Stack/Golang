Практика: Банковский терминал

Ты делаешь маленькую программу для банка. Клиент может проверить баланс, пополнить счёт или снять деньги.

1. Создай структуру Account

Поля:

name     string
balance  float64
active   bool
2. Создай методы
Deposit(amount float64) error

Пополняет баланс.

Правила:

если счёт неактивен → ошибка;
если сумма меньше или равна 0 → ошибка;
иначе добавить деньги.
Withdraw(amount float64) error

Снимает деньги.

Правила:

если счёт неактивен → ошибка;
если сумма меньше или равна 0 → ошибка;
если денег недостаточно → ошибка;
иначе снять деньги.
Balance() float64

Просто возвращает баланс.

3. main()

Создай аккаунт:

name: Ali
balance: 1000
active: true

Затем программа должна спросить:

Введите операцию:
1 - Пополнить
2 - Снять
3 - Проверить баланс
4 - Выход

Пользователь вводит номер через Scanln.

Если 1

Спроси:

Введите сумму:

Затем вызови Deposit().

Если появилась ошибка — выведи её.

Если всё хорошо:

Баланс пополнен!
Если 2

Спроси:

Введите сумму:

Вызови Withdraw().

При успехе:

Деньги сняты!

При ошибке — покажи ошибку.

Если 3

Выведи:

Ваш баланс: 1000
Если 4

Выведи:

Программа завершена.
Главное

Сделай меню в for, чтобы программа не завершалась после одной операции.

Например:

Введите операцию:
1 - Пополнить
2 - Снять
3 - Баланс
4 - Выход

> 1

Введите сумму:
> 500

Баланс пополнен!

Введите операцию:
1 - Пополнить
2 - Снять
3 - Баланс
4 - Выход

> 3

Ваш баланс: 1500

А потом специально проверь ошибку:

> 2

Введите сумму:
> 2000

Ошибка: недостаточно денег

Вот эту версию уже рекомендую делать самому. Здесь есть struct → методы → if → for → Scanln → error
