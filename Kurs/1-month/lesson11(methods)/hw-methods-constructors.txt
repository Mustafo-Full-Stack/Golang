Структуры и методы

1. Опиши структуру `Wallet` с приватным полем `balance` (float64). Добавь методы `Deposit(amount float64) error` (ошибка, если сумма отрицательная), `Withdraw(amount float64) error` (ошибка, если не хватает денег) и `Balance() float64`. В main() сделай несколько операций подряд и выведи баланс после каждой, а на одной операции специально получи и выведи ошибку.

2. Структура `Song` (`Title` string, `Duration` int — в секундах). Структура `Playlist` с приватным полем-срезом `Song`. Методы: `Add(s Song)`, `TotalDuration() int`, `Longest() Song`, `String() string` — чтобы `fmt.Println(playlist)` печатал список треков по одному на строку. Собери плейлист из 4-5 песен и выведи его, общую длительность и самый длинный трек.

3. Структура `Inventory` (склад) с приватным полем `map[string]int` — товар и его количество. Методы: `Add(item string, qty int)`, `Remove(item string, qty int) error` (ошибка, если товара не хватает или его вообще нет), `Count(item string) int`, `Total() int` — сумма количества всех товаров на складе.

4. Структура `Matrix` на основе `[][]float64`. Методы `Rows() int`, `Cols() int`, `Sum() float64` (сумма всех элементов) и `Transpose() Matrix` (транспонированная матрица). Проверь на матрице 2x3.

5. Структура `Point` (`X`, `Y` float64) с методом `DistanceTo(other Point) float64`. Структура `Polygon` на основе `[]Point` с методом `Perimeter() float64` — сумма расстояний между соседними точками, включая расстояние от последней точки до первой.

6. Структура `Employee` (`Name` string, `Salary` float64, `YearsWorked` int) с методом `Bonus() float64` — 10% от зарплаты за каждые полные 5 лет стажа. Структура `Company` на основе `[]Employee` с методами `TotalPayroll() float64` (зарплаты + бонусы всех сотрудников) и `TopEarner() Employee` (самый высокооплачиваемый с учётом бонуса).

7. Структура `Order` (`ID` int, `Amount` float64). Структура `OrderQueue` с приватным полем-срезом заказов — очередь "первый пришёл, первый ушёл". Методы: `Enqueue(o Order)`, `Dequeue() (Order, error)` (ошибка, если очередь пуста), `IsEmpty() bool`, `TotalAmount() float64` — сумма по всем заказам в очереди.

Структуры + встраивание (посложнее)

8. Структура `Animal` (`Name`, `Sound` string) с методом `MakeSound() string`, возвращающим что-то вроде "Bobik говорит Гав". Структуры `Dog` и `Cat` встраивают `Animal` и переопределяют `MakeSound()`, добавляя что-то своё поверх базового поведения (например, дописывая "(виляет хвостом)"). Собери срез из нескольких животных разных типов и вызови `MakeSound()` для каждого.

9. Структура `Person` (`Name` string, `Age` int) с методом `Info() string`. Структура `Student` встраивает `Person`, добавляет поле `University` и переопределяет `Info()`, вызывая внутри себя `Info()` встроенного `Person` и дописывая к результату университет.

10. Структура `Node` (`Value int`, `Next *Node`) — односвязный список. Метод `(head *Node) Append(v int) *Node` добавляет новый узел в конец и возвращает исходную голову списка. Функция `PrintList(head *Node)` проходит по списку через `for` и печатает значения через " -> ". Собери список из 5 чисел и выведи его.

Смешанные задачи 

11. Структура `Student` (`Name` string, 
`Grades []int`) с методами `Average() float64` и `String() string`. 

Дан срез `[]Student` из 5-6 студентов — с помощью `Average()`
найди старосту (студента с лучшим средним баллом) и выведи его.

12. Структура `BankAccount` (`Owner` string, приватное поле `balance` float64) с методами `Deposit` и `Withdraw` на pointer-receiver'е. Напиши отдельную функцию `Transfer(from, to *BankAccount, amount float64) error`, которая снимает деньги с одного счёта и кладёт на другой, а если снятие не удалось (не хватает денег) — возвращает ошибку и не трогает второй счёт.

13. Структура `Task` (`Title` string, `Priority` int, `Done` bool) с методом `(t *Task) Complete()`. Дан срез `[]Task` из 6 задач с разными приоритетами — отсортируй его по `Priority` пузырьком (циклами, без пакета sort) и выведи список до и после сортировки.

14. Напиши функцию `NewIDGenerator() func() int`, которая через замыкание выдаёт очередной уникальный ID при каждом вызове, начиная с 1. Используй её, чтобы создать срез из структур `User` (`ID int`, `Name string`), присваивая ID не вручную, а вызовом функции-замыкания.

15. Структура `Category` (`Name` string, `Sub []Category`) — дерево категорий товаров (у категории есть подкатегории, у тех — свои и так далее). Напиши рекурсивную функцию `CountAll(c Category) int`, которая считает количество всех категорий в дереве, включая саму `c` и все вложенные на любом уровне глубины.

16. Структура `Contact` (`Name`, `Phone` string). Структура `AddressBook` с приватным полем `map[string]Contact` (ключ — короткое имя контакта). Методы `Add(key string, c Contact)`, `Find(key string) (Contact, bool)`, `Delete(key string)`. Продемонстрируй все три метода в main(), включая попытку найти несуществующий контакт.

17. Структура `Character` (`Name` string, `HP`, `Attack` int) с методами `IsAlive() bool`, `TakeDamage(dmg int)` и `AttackTarget(target *Character)`. В main() создай двух персонажей и в цикле `for` устраивай бой — по очереди атакуй друг друга, пока один не останется в живых, выводя HP после каждого удара. Выведи, кто победил.

Ещё немного практики 

18. Структура `Robot` с приватными полями `x`, `y` (int) — координаты на сетке. Методы `MoveUp()`, `MoveDown()`, `MoveLeft()`, `MoveRight()` — каждый сдвигает робота на 1 клетку в соответствующую сторону, `Position() (int, int)` и `String() string`, печатающий что-то вроде "Robot @ (3, -1)". В main() подвигай робота в разные стороны по очереди и после каждого шага выведи его текущую позицию.

19. Структура `TrafficLight` (светофор) с приватным полем — текущим цветом. Метод `Next()` переключает цвет по кругу: красный → жёлтый → зелёный → красный, метод `Current() string` возвращает текущий цвет, `String() string` — для красивой печати. В main() запусти светофор в цикле на 6-7 переключений и выведи, как меняются цвета.

20. Структура `Stack` с приватным полем — срезом `int` (стек, "последним пришёл — первым ушёл"). Методы `Push(v int)`, `Pop() (int, error)` — ошибка, если стек пуст, и `IsEmpty() bool`. В main() положи в стек несколько чисел, достань пару значений через `Pop()` и выведи результат, а затем попробуй вызвать `Pop()` на пустом стеке и вывести полученную ошибку.

21. Структура `Player` (`Name` string, `Score` int) с методом `AddPoints(p int)`. Дан срез `[]Player` из 4-5 игроков — напиши функцию `TopPlayer(players []Player) Player`, которая находит игрока с наибольшим счётом. Начисли игрокам очки в разном порядке и выведи победителя.

22. Структура `Canvas` на основе `[][]rune` — прямоугольное поле фиксированного размера, изначально заполненное пробелами. Методы `SetPixel(x, y int, c rune) error` — закрасить клетку символом `c`, с ошибкой, если координаты вне поля, и `Print()` — вывести холст построчно. В main() создай холст 8x4 и нарисуй на нём простую линию через несколько вызовов `SetPixel`.

Конструкторы

23. Структура `Config` (`Host` string, `Port` int, `Timeout` int). Конструктор `NewConfig(host string, port int) *Config` создаёт конфиг и сам выставляет `Timeout` в 30, раз пользователь его не передаёт. Выведи созданный конфиг и убедись, что `Timeout` заполнен без ручной установки.

24. Структура `Rectangle` (приватные `width`, `height` float64) с методами `Area() float64` и `Perimeter() float64`. Конструктор `NewRectangle(width, height float64) (*Rectangle, error)` возвращает ошибку, если ширина или высота не положительны. В main() попробуй создать прямоугольник с отрицательной стороной и выведи ошибку, затем создай нормальный и выведи его площадь и периметр.

25. Структура `Queue` с приватным полем-срезом `int`. Конструктор `NewQueue() *Queue` сразу инициализирует пустой срез внутри, чтобы после создания можно было добавлять элементы без лишних проверок. Методы `Enqueue(v int)` и `Dequeue() (int, error)`. Покажи в main(), что сразу после `NewQueue()` очередь готова к работе.

26. Структура `Car` (`Brand`, `Model` string, приватное поле `mileage` int) с методом `Drive(km int)`, увеличивающим пробег. Два конструктора: `NewCar(brand, model string) *Car` — новая машина с пробегом 0, и `NewUsedCar(brand, model string, mileage int) *Car` — машина с уже заданным пробегом. Продемонстрируй в main() создание машины через оба конструктора.

27. Структура `Logger` с приватными полями `prefix string` и `count int`. Конструктор `NewLogger(prefix string) *Logger`. Метод `Log(msg string)` при каждом вызове увеличивает счётчик и печатает что-то вроде "[prefix] msg (#N)". В main() создай два логгера с разными префиксами и залогируй через каждый по паре сообщений.

Что считается сделанным: receiver выбран осознанно (value — если метод не меняет состояние, pointer — если меняет) и не смешивается для одного типа; приватные поля не читаются и не меняются напрямую снаружи, только через методы.
